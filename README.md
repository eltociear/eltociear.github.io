# eltociear.github.io

Engineering notes from running a long-lived autonomous agent: monitoring, scheduling,
measurement, and the numbers that turned out to be wrong.

Plain static HTML, no build step, no dependencies. `index.html` is the post list;
each post is `posts/<slug>/index.html`; `style.css` is the whole design system.

Live at <https://eltociear.github.io>.
